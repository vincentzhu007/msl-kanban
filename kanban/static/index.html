指标口径

  • 当前协议：上下文 2K、输入 1K、输出 128，后续每组连续推理 10 次；历史记录保留原次数，表格前展示实际规格。
  • ROM 为模型文件大小，不包含运行库。RAM 为 hidumper 总 PSS，已包含 Graph / NPU；峰值为全程采样峰值，可能漏掉瞬时峰值。
  • 初始化为每进程一次的模型与运行上下文准备时延，不是 P90，也不保证冷文件缓存。看板 Prefill 包含 Tokenizer 分词、输入计算、首 token 采样及回调前的接口开销，与 TTFT 使用同一计时边界，不包含初始化。Prefill 速度 = 输入 token 数 × 1000 ÷ TTFT P90（ms），是 P90 时延对应的速度，不是速度样本的 P90；最近秩 P90：10 次取升序第 9 个值；历史 5 次取最大值。
  • TPOT 为每次 Decode 耗时 ÷（实际输出 token 数 − 1），再对各次结果取最近秩 P90；不包含首 token，越低越好。无有效样本时显示 —。
  • Decode P90 为各次生成速度的最近秩 P90，单位 token/s，越高越好；5 次样本时为最高速度，与 TPOT P90 不互为倒数。
  • 稳定内存样本数随记录展示；当前数据用于观测，不代表已完成环境资格认证的正式性能基线。
